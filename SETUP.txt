To use the website locally, open index.html or run `python3 -m http.server 8000` and visit http://localhost:8000.

For GitHub Pages, push index.html, app.js, styles.css, lyrics.txt, and song/dahan.mp3 to the repository. In Settings > Pages, select Deploy from a branch and choose the repository branch with the /(root) folder.

Lyrics are read from lyrics.txt, one line per row. Lines starting with # are ignored. Prefix a line with milliseconds and a bar to change its duration, for example `5200|your lyric here`.
